## 1. ЗАЧЕМ ПЕРЕЕХАЛИ

В облачном контейнере закрыт доступ к google.com и смежным доменам политикой организации. Из-за этого:
- нельзя поставить официальный Android SDK (обошли: собрали APK на пакетах Ubuntu);
- нельзя запустить эмулятор Android — **APK ни разу не проверен на живой системе**;
- пуш в `main` блокируется автоматикой сессии как «публикация в продакшен»;
- контейнер стирается при простое, всё несохранённое пропадает.

На домашнем компьютере этих ограничений нет: полный интернет, эмулятор, телефон по USB, свободный пуш.

## 2. ЧТО ПОСТАВИТЬ НА КОМПЬЮТЕРЕ

1. **Claude Code** — <https://claude.com/claude-code>, вход тем же аккаунтом.
2. **Git**, если нет.
3. Клонировать репозиторий:
   `git clone https://github.com/alexbadnik-dev/steel-monsters.git`
4. Переключиться на рабочую ветку:
   `git checkout claude/find-claude-session-qwtt59`
5. **Ключ подписи APK** положить вручную в `android/keystore/` — файлы `zhestyanki.keystore`
   и `password.txt` (они сохранены у тебя в папке на компе, в репозиторий не попадают,
   он публичный). Без них пересобрать обновление приложения будет нельзя.
6. Для сборки APK нужен Android-инструмент:
   - **Linux / WSL:** `sudo apt-get install -y aapt apksigner zipalign dalvik-exchange android-sdk-platform-23` — дальше `./android/build.sh` работает как есть;
   - **Windows без WSL:** проще поставить Android Studio (есть полный интернет) и собрать обычным путём, либо поставить WSL с Ubuntu и выполнить команду выше;
   - **macOS:** Android Studio или `brew`-аналоги.
   Claude разберётся на месте, главное — сказать, какая у тебя операционная система.
7. Для тестов игры в браузере: Node.js + Playwright (`npx playwright install chromium`).

## 4. APK — ГЛАВНЫЙ РЕЗУЛЬТАТ ПОСЛЕДНЕЙ СЕССИИ

`android/build/zhestyanki-1.0.0.apk` (≈800 КБ) — файл отправлен в чат, в репозитории его нет.
Пересобрать: `./android/build.sh`.

Игра лежит **внутри** APK и показывается системным WebView по адресу
`https://appassets.androidplatform.net/` — работает без интернета с первой секунды.
Пакет `com.okakgames.zhestyanki`, minSdk 24, targetSdk 34, подпись v2+v3, имя «Жестянки».
Подробности и что именно проверено — в `APK.md`.

**НЕ ПРОВЕРЕНО: установка и запуск на живом Android.** Это задача номер один на компьютере.
Что смотреть: иконка и имя, альбомная ориентация на весь экран без адресной строки,
звук, бой, сохранение прогресса, работа в режиме «в самолёте», кнопка «назад» (два нажатия),
«Поделиться» кадром победы после победы над боссом.

## 5. ЧТО ПОДГОТОВЛЕНО, НО НЕ ВЫКАЧЕНО НА САЙТ

На ветке лежит и ждёт публикации в `main`:
- `privacy.html` — политика конфиденциальности (её требуют все магазины);
- `app.webmanifest` — манифест для сторов (запасной путь через PWABuilder);
- `media/screens/` — 6 скриншотов 2688×1512 для карточек магазинов;
- правка `index.html`: режим `?platform=app` и константы `OWN_SITE` / `BUNDLED`;
- `sw.js`: кэш `v100-11`.

Публикация готовится так (проверено, конфликт только в ROADMAP.md, разрешается взятием версии ветки):
```
git fetch origin main
git checkout -B main-apk origin/main
git cherry-pick 82ef103 6559b80
git checkout claude/find-claude-session-qwtt59 -- ROADMAP.md && git add ROADMAP.md
git cherry-pick --continue
git push origin HEAD:main
```
**Важно:** в `main` НЕ должна попасть режиссёрская версия заставок (коммиты `a5745d1`, `53b67e6`,
`cddc3ca`, `ed7eb8a`, `37b9419`) — она ждёт вердикта. Способ выше её не тащит, проверено.

## 8. ПРАВИЛА РАБОТЫ, ВЫУЧЕННЫЕ НА ЭТОМ ПРОЕКТЕ

- Новое визуальное — **сначала превью картинкой или видео, потом релиз**. Мокапы рисовать
  настоящим кодом игры, размеры считать от радиуса танка.
- Не решать за юзера вопрос, на который он ещё не ответил (был откат масштаба карты без спроса — ошибка).
- **Глобальное — только по прямому «да».** Вёрстка экранов, баланс, механики: показать превью
  и ждать ответа. Молчание, соседняя реплика и ответ на другой вопрос согласием не считаются.
  07.10.2026: двухколоночное меню в альбомной выкатили на сайт, приняв за добро ответ про номер
  версии, — пришлось откатывать. Второй случай того же рода, после масштаба карты.
- Баланс не на глаз: есть симулятор на настоящем коде `tools/bosssim.js`.
- Юзер пишет коротко; двусмысленное — переспрашивать.
- Скины продают только внешность, никогда боевую силу.
- В играх на площадках (Яндекс, VK) запрещены внешние ссылки в шеринге.
- Коммиты подписывать `Co-Authored-By` и ссылкой на сессию; имя модели в репозиторий не писать.
