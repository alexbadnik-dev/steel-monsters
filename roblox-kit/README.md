# «Жестянки» → Roblox Studio: стартовый пакет

Наша игра сделана на JavaScript для браузера, а Roblox — свой 3D-движок с языком Luau.
Файл игры туда загрузить нельзя: в Roblox игру собирают заново. Этот пакет — всё,
что для этого нужно: правила и цифры, картинки и заготовки скриптов.

## Что внутри

| Папка / файл | Что это | Как использовать в Roblox |
|---|---|---|
| `GDD.md` | Описание игры: правила, враги, боссы, биомы, бонусы, скины, все цифры | Читать и собирать по нему |
| `game-data.json` | Те же цифры в виде данных (прямо из кода игры) | Подсматривать точные значения |
| `sprites/player/` | 42 танка игрока (вид сверху, ствол вверх) | Decal на верх танка / иконки магазина |
| `sprites/enemies/` | 7 типов врагов | Decal на врагов |
| `sprites/bosses/` | 10 боссов сверху | Decal на босса |
| `sprites/bosses_side/` | 10 боссов сбоку (как в заставках) | Картинки для интерфейса, экран победы |
| `sprites/pickups/` | Ящики бонусов: аптечка, щит, скорострел, тройной, заморозка, магнит, луч | Иконки бонусов |
| `sprites/props/` | Бочка, противотанковый ёж (обычный и ржавый) | Decal / ImageLabel |
| `scenes/` | 10 кадров кино-глав 1280×720 | Экран загрузки, обложка, фон меню |
| `scripts/Zhestyanki.server.lua` | Сервер: волны, враги, боссы, пули, чекпоинт | `ServerScriptService` → **Script** |
| `scripts/TopDown.client.lua` | Камера сверху, стрельба, надпись волны | `StarterPlayer → StarterPlayerScripts` → **LocalScript** |

## Быстрый старт (15 минут)

1. Открой **Roblox Studio** → **New** → шаблон **Baseplate**.
2. В окне **Explorer** найди **ServerScriptService** → «+» → **Script**. Удали строчку
   `print("Hello world!")` и вставь весь текст из `scripts/Zhestyanki.server.lua`.
3. **StarterPlayer** → **StarterPlayerScripts** → «+» → **LocalScript**, вставь
   `scripts/TopDown.client.lua`.
4. Нажми **Play** (F5). Камера встанет сверху, через пару секунд поедут враги.
   Ходить — WASD, стрелять — левая кнопка мыши или пробел. Каждая 10-я волна — босс.

## Как поставить наши картинки

1. **View → Asset Manager** (или **Window → Asset Manager**) → **Import** / **Bulk Import**.
   Выбери PNG из папки `sprites` — Studio загрузит их на Roblox.
2. Правый клик по картинке → **Copy Asset ID** (получится `rbxassetid://12345…`).
3. В `Zhestyanki.server.lua` вставь этот id в поле `decal = ""` нужного врага — картинка
   ляжет на верх танка. Для игрока и интерфейса — **Decal** или **ImageLabel** с этим id.

Загрузка картинок и звуков проходит модерацию Roblox (обычно минуты). У детских
аккаунтов (до 13 лет) часть функций загрузки может быть ограничена — тогда загружает папа.

## Звуки и музыка

В веб-версии звуки не лежат файлами — они синтезируются кодом «на лету», поэтому в
пакете их нет. Их можно записать в `.ogg` / `.mp3` отдельно (это следующий шаг, если
понадобится), а пока — взять бесплатные звуки из **Toolbox → Audio** в Studio.

## Что дальше строить (по порядку)

1. Танк вместо человечка: модель танка (StarterCharacter) или Part с нашим Decal.
2. Ящики-бонусы: падают с врагов (32% на Норме), аптечка +25 HP, тройной выстрел и т.д.
3. Биомы: каждые 10 волн — новая земля (цвета — в `GDD.md`).
4. Магазин скинов за монеты (20 очков = 1 монета) — цены в `GDD.md`.
5. Сложности Норма / Хард / Кошмар — множители в `GDD.md`.

Скрипты — рабочая заготовка, проверенная на синтаксис Lua, но не запущенная в самой
Roblox Studio (у нас её нет). Если Studio покажет ошибку — пришли текст ошибки, поправим.

## ВЕРСИЯ 2 — наш танк, наши картинки, игра с друзьями

Файл: `scripts/v2/Zhestyanki2.server.lua`. Номера всех картинок уже вписаны (из Asset Manager папа прислал).

1. В **ServerScriptService** у старого скрипта (версия 1) сними галочку **Enabled** (или удали его).
2. Там же «+» → **Script**, вставь весь текст `Zhestyanki2.server.lua`.
3. LocalScript `TopDown` (камера и стрельба) оставь как был.
4. Большой белый квадрат со звездой — это **SpawnLocation** шаблона (точка появления), его можно не трогать.
5. **Play**. Ты — танк (вместо человечка). Друзья на сервере получают свои скины.

Что есть: враги и боссы с нашими картинками; ящики (аптечка, щит, скорострел, тройной) — подбираются наездом;
бочки взрываются (цепная реакция), ежи держат пули; каждые 10 волн — новый биом (цвет земли);
справа вверху — таблица очков и волны. Если ствол на картинках смотрит не по ходу — `SPRITE_YAW` в начале скрипта: 180, 90 или -90.
Друзей проверить в Studio: вкладка **Test → Clients and Servers → 2 Players → Start**.

### Вращающиеся башни (листы корпусов и башен)
`sheets/tanks_hull.png` и `sheets/tanks_turret.png` — по 59 танков на листе (скины, враги, боссы).
Загрузи **оба файла** в Asset Manager и впиши номера в начало скрипта версии 2:
`SHEET_HULL = "номер"` и `SHEET_TURRET = "номер"`. Корпус поворачивается по ходу, башня — на цель
(у игрока — за мышкой). Нужен и обновлённый LocalScript `TopDown.client.lua` (шлёт прицел серверу).
