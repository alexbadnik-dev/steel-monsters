# RuStore — что заливать и куда

Файл сборки: `zhestyanki-1.0.0.apk` рядом с этим README.
Пересобирается командой `bash android/build.sh` (кладёт свежий в `android/build/`).
Подробности про APK и про то, что чем собрано, — в [APK.md](../APK.md).

## Куда идти

<https://console.rustore.ru> — вход по Госуслугам, аккаунт бесплатный.
68 млн пользователей в месяц, обязателен к предустановке на новых Android в РФ,
комиссия 15%, тестировщиков перед релизом не требует. Поэтому RuStore идёт
первым из магазинов приложений, раньше AppGallery и Google Play.

## Чего не хватает для заливки

**Политика конфиденциальности.** Её требуют все магазины. Файл готов
(`../privacy.html`), но в нём стоит заглушка `ПОЧТА_ДЛЯ_СВЯЗИ`, и сам файл
ещё не выкачен на сайт — ссылка из STORE.md пока отдаёт 404.
Два решения ждут юзера: какая почта и где хостить (GitHub Pages или свой домен —
модератор RuStore сидит в России, и если ссылка у него не откроется, заявку отклонят).

## Порядок

1. Решить вопрос с почтой и местом для политики, вписать адрес в `privacy.html`.
2. Выкатить `privacy.html` на сайт и проверить, что ссылка открывается.
3. Завести кабинет на console.rustore.ru (Госуслуги).
4. Залить APK, заполнить карточку, приложить скриншоты и ссылку на политику.
5. Отправить на модерацию.

## Проверка APK перед заливкой

```
bash android/build.sh          # собирает и сам себя проверяет: подпись, выравнивание, манифест
node tools/apk-webtest.js      # гоняет содержимое APK в браузере с выключенным интернетом
```

Установка на телефон по USB:
`D:/Android/sdk/platform-tools/adb.exe install -r android/build/zhestyanki-1.0.0.apk`

**На живом Android приложение ещё не запускали** — это главная непройденная проверка.
Что смотреть при первом запуске — в `APK.md`.
