# APK «Жестянки»: как собираем приложение для сторов

Нужен для RuStore, Huawei AppGallery и Google Play. Яндекс и VK — это HTML5-площадки,
им APK не нужен (туда уходят `dist/yandex.zip` и `dist/vk.zip`).

## Почему не собираю APK сам

Проверено 06.10.2026: из контейнера Клода закрыт доступ к `dl.google.com` и
`maven.google.com` (политика организации), а `aapt2` и `r8` на Maven Central не лежат.
Значит, Android SDK не поставить и APK не собрать. Собирать байты вручную — часы работы,
высокий шанс получить нерабочий файл, и проверить его негде (Android у меня нет).
Поэтому собираем через **PWABuilder** — это официальный инструмент Microsoft, который
заворачивает сайт в приложение (Trusted Web Activity) и подписывает его.

Приложение — это наш же сайт внутри окна Android: один код, одни обновления.
Обновил сайт — обновилось приложение, без повторной заливки в стор.

## Что уже готово в репозитории

| Файл | Зачем |
|---|---|
| `app.webmanifest` | Манифест именно для сторов: имя «Жестянки», альбомная ориентация, полный экран, скриншоты |
| `manifest.webmanifest` | Остался для сайта: имя «Стальные монстры» |
| `media/screens/*.png` | 6 скриншотов 2688×1512 (16:9) для карточек магазинов |
| `privacy.html` | Политика конфиденциальности — её требуют все сторы |
| `index.html` | Понимает `?platform=app`: называется «ЖЕСТЯНКИ», ссылка в шеринге и офлайн-кэш остаются |

**Перед публикацией:** в `privacy.html` вписать настоящую почту вместо `ПОЧТА_ДЛЯ_СВЯЗИ`.

## Шаг 1. Собрать пакет на PWABuilder

1. Открыть <https://www.pwabuilder.com/>, вставить адрес:
   `https://alexbadnik-dev.github.io/steel-monsters/`
2. Нажать **Package for stores** → **Android** → **All settings** (развернуть все поля).
3. Вписать:

| Поле | Значение |
|---|---|
| Manifest URL | `https://alexbadnik-dev.github.io/steel-monsters/app.webmanifest` |
| Package ID | `com.okakgames.zhestyanki` — **потом его не сменить никогда** |
| App name | `Жестянки` |
| Launcher name | `Жестянки` |
| App version | `1.0.0` |
| App version code | `1` |
| Host | `alexbadnik-dev.github.io` |
| Start URL | `/steel-monsters/index.html?platform=app` |
| Display mode | `Fullscreen` |
| Orientation (если есть) | `Landscape` |
| Status bar / Nav bar color | `#171c22` |
| Signing key | **Create new** |

4. **Download** → получится zip. Внутри:
   - `app-release-signed.apk` — поставить на телефон и проверить;
   - `app-release-bundle.aab` — то, что загружают в Google Play;
   - `assetlinks.json` — доказательство, что сайт наш (см. шаг 2);
   - `signing.keystore` + `signing-key-info.txt` — **ключ подписи**.

> **Ключ подписи — самое важное в этом zip.** Потеряешь — обновить приложение в сторе
> будет невозможно никогда, только публиковать заново под другим именем пакета.
> Положить в облако и ещё на флешку. В репозиторий НЕ класть: он публичный.

## Шаг 2. Подтвердить, что сайт наш (иначе сверху будет адресная строка)

Android проверяет файл по адресу **в корне домена**:
`https://alexbadnik-dev.github.io/.well-known/assetlinks.json`

Корень `alexbadnik-dev.github.io` обслуживается отдельным репозиторием с таким же именем —
сейчас его нет. Поэтому:

1. На GitHub создать **публичный** репозиторий с именем ровно `alexbadnik-dev.github.io`.
2. Сказать мне — я положу туда `.well-known/assetlinks.json` (из zip'а) и `.nojekyll`
   (без него GitHub Pages прячет папки с точкой), и включу Pages.
3. Проверить, что ссылка выше открывается и отдаёт JSON.

Пока этого файла нет, приложение запустится, но сверху будет видна полоса с адресом сайта —
в стор с такой не отдаём.

## Шаг 3. Проверить на телефоне

Скинуть `app-release-signed.apk` на телефон, разрешить установку из неизвестных источников,
поставить. Смотрим:
- иконка и имя «Жестянки»;
- нет адресной строки сверху;
- игра сразу в альбомной ориентации, на весь экран;
- после первого запуска работает в режиме «в самолёте» (офлайн-кэш).

## Шаг 4. Разложить по сторам

Порядок наш прежний: **RuStore → Huawei AppGallery → Google Play**.

- **RuStore** (<https://console.rustore.ru>) — бесплатно, вход по Госуслугам/телефону,
  принимает APK или AAB. Нужны: иконка 512×512, 4–6 скриншотов (берём `media/screens/`),
  описание, возрастной рейтинг (6+), ссылка на `privacy.html`.
- **Huawei AppGallery** (<https://developer.huawei.com/consumer/ru/>) — регистрация
  разработчика с подтверждением личности, дальше так же.
- **Google Play** — 25 $ разово и 14 дней закрытого теста с 12 тестировщиками,
  поэтому последним. Туда загружается `.aab`.

Описание и тексты карточек — отдельным шагом, когда дойдём до заливки.
