# VK — что заливать и куда

Файл сборки: `vk.zip` рядом с этим README (пересобирается командой `./build-platforms.sh`,
он же кладёт копию в `dist/`). Внутри: `index.html` и три иконки, без папок — площадки
ждут `index.html` в корне архива.

## Куда идти

<https://dev.vk.com> → «Мои приложения» → создать приложение.
Два варианта размещения, оба бесплатные:

| Куда | Что это | Аудитория |
|---|---|---|
| VK Mini Apps | игра внутри ВК, открывается в приложении и на сайте | 45 млн MAU |
| VK Play | отдельный игровой портал | 13+ млн MAU |

Разработчику остаётся 95% выручки — самая мягкая комиссия из всех площадок.
От Яндекса заливка сюда никак не зависит, можно делать параллельно.

## Что уже готово в коде

- платформа определяется сама (`PLATFORM` по домену или `?platform=vk`);
- `vk-bridge` подключается автоматически: `VKWebAppInit`, rewarded-реклама
  на кнопке «МОНЕТЫ ×2» на экранах результата боя;
- сервис-воркер на площадках не регистрируется;
- в «Поделиться» нет внешних ссылок — это требование площадок.

## Порядок

1. Создать приложение на dev.vk.com, выбрать тип (Mini App).
2. Залить `vk.zip`, проверить в их отладчике — особенно rewarded-рекламу.
3. Заполнить карточку текстами из `STORE.md`, приложить скриншоты.
4. Отправить на модерацию.

## Открытые вопросы

- Лидерборд и сохранения: на Яндексе игра ходит в их SDK, на сайте — в Supabase.
  Для VK пока работает путь сайта (Supabase). С мобильного интернета в РФ Supabase
  местами режут — если в VK это вылезет, повторим приём Яндекса и переведём
  рейтинг с сейвами на VK Bridge.

## Оформление кабинета

Все картинки, ролик и анимированная иконка под вкладки «Оформление» — в подпапке
[оформление/](оформление/README.md): там таблица «какой файл в какое поле» и размеры,
которые требует ВК. Пересобираются скриптами `tools/vk-icons.py`, `tools/vk-art.js`,
`tools/vk-lottie.py`.
