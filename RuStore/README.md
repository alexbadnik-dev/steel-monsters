# RuStore — что заливать и куда

Файл сборки: `zhestyanki-1.0.0.apk` рядом с этим README.
Пересобирается командой `bash android/build.sh` (кладёт свежий в `android/build/`).
Подробности про APK и про то, что чем собрано, — в [APK.md](../APK.md).

## Куда идти

<https://console.rustore.ru> — вход по Госуслугам, аккаунт бесплатный.
68 млн пользователей в месяц, обязателен к предустановке на новых Android в РФ,
комиссия 15% только с платежей, тестировщиков перед релизом не требует. Поэтому RuStore
идёт первым из магазинов приложений, раньше AppGallery и Google Play.

## Единственное, чего не хватает

**Почта в политике конфиденциальности.** Файл `../privacy.html` уже выложен и открывается
по <https://alexbadnik-dev.github.io/steel-monsters/privacy.html>, но в нём живьём стоит
заглушка `ПОЧТА_ДЛЯ_СВЯЗИ`. Модераторы отдельно смотрят, чтобы политика была не формальной
и с настоящими контактами, так что с заглушкой заявку развернут.

Ждём домен `okakgames.ru` → `support@okakgames.ru` → одна правка в `privacy.html` → выкатка.

Поле «Контакт разработчика» в самой карточке почты не требует — там достаточно сайта.
Упор только в политику.

## Порядок

1. Завести кабинет на `console.rustore.ru` (Госуслуги) — **можно делать уже сейчас**.
2. Дождаться домена, вписать почту в `privacy.html`, выкатить на сайт.
3. Залить APK, заполнить карточку текстами из `STORE.md`, приложить скриншоты
   и ссылку на политику.
4. Отправить на модерацию.

## Проверка APK перед заливкой

```
bash android/build.sh          # собирает и сам себя проверяет: подпись, выравнивание, манифест
node tools/apk-webtest.js      # гоняет содержимое APK в браузере с выключенным интернетом
```

Установка на телефон по USB:
`D:/Android/sdk/platform-tools/adb.exe install -r android/build/zhestyanki-1.0.0.apk`

## Поворот экрана — проверить заново

Юзер ставил APK на телефон 09.10 и сказал, что меню не поворачивается. **Выяснилось 15.10,
что тот APK был собран за восемь минут до правки** — в нём её просто не было.
В нынешней сборке `screenOrientation=0xa` (fullSensor) и мост `AndroidApp` на месте.
Поставить заново и проверить: меню должно крутиться вслед за телефоном, бой оставаться
альбомным.
