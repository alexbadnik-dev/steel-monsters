# APK «Жестянки» — как собран и что с ним делать

Файл: `android/build/zhestyanki-1.0.0.apk` (≈800 КБ).
Собирается одной командой: `./android/build.sh`.

## Что это за приложение

Игра целиком лежит **внутри** APK — index.html, шрифты и иконки в `assets/`.
Показывает её системный WebView (это тот же Chromium, что в Chrome на телефоне).
Поэтому:

- **работает без интернета с первой же секунды** — ничего не скачивается;
- запускается мгновенно, адресной строки нет, экран альбомный и на весь экран;
- интернет нужен только для общей таблицы рекордов; нет сети — игра молчит об этом и играется дальше;
- обновление игры = новый APK (в отличие от варианта «обёртка над сайтом»).

Что сделано отдельно для приложения:
- адрес внутри приложения `https://appassets.androidplatform.net/` — настоящий https-адрес,
  поэтому сохранения (localStorage) и запросы к рекордам работают как на сайте;
- `?platform=app` — игра называется «ЖЕСТЯНКИ», как в сторе;
- сервис-воркер не регистрируется (файлы и так внутри приложения);
- шрифты Russo One и Press Start 2P зашиты в APK (лицензия OFL, файл `LICENSE-fonts.txt`),
  иначе без интернета игра выглядела бы чужим шрифтом;
- «Поделиться» кадром победы работает через системную шторку Android;
- кнопка «назад» — два нажатия подряд, чтобы не выйти случайно посреди боя;
- экран не гаснет во время игры, телефон вибрирует на взрывах.

## Чем собрано (без Android Studio и без Google)

`dl.google.com` и `maven.google.com` закрыты политикой контейнера, зато в репозиториях
Ubuntu лежит весь нужный инструмент:

```
sudo apt-get install -y aapt apksigner zipalign dalvik-exchange android-sdk-platform-23
```

`build.sh` делает: javac → dex (dalvik-exchange) → aapt package → zipalign → apksigner,
потом сам себя проверяет (подпись, выравнивание, содержимое).

| Параметр | Значение |
|---|---|
| Имя пакета | `com.okakgames.zhestyanki` — **сменить потом нельзя** |
| Название | Жестянки |
| Версия | 1.0.0 (versionCode 1) |
| Android | от 7.0 (minSdk 24) до самых новых (targetSdk 34) |
| Подпись | RSA 4096, срок 30 лет, схемы v2 + v3 |
| Разрешения | интернет, состояние сети, вибрация |
| Размер | ≈800 КБ |

## Ключ подписи — самое важное

`android/keystore/zhestyanki.keystore` и пароль `android/keystore/password.txt`.
В репозиторий они НЕ попадают (прописаны в `.gitignore`), потому что он публичный.

**Потеряешь ключ — обновить приложение в сторе будет нельзя никогда**, только публиковать
заново под другим именем пакета и с потерей всех установок. Положи файл и пароль
в облако и ещё на флешку.

## Что проверено, а что нет — честно

Проверено здесь:
- APK собирается, подпись проходит `apksigner verify` (v2 и v3), выравнивание верное;
- манифест: имя пакета, версии, альбомная ориентация, launcher-активность, провайдер для «Поделиться»;
- dex содержит все наши классы, собран против Android API 23 — значит ни одного вызова,
  которого нет на Android 7+;
- внутренности APK запущены в Chromium ровно так, как их увидит WebView
  (адрес `appassets.androidplatform.net`, интернет выключён): меню и бой работают,
  свои шрифты подхватились, сохранения переживают перезапуск, сервис-воркер не лезет,
  наружу уходит только запрос к таблице рекордов;
- вставка JavaScript, которую приложение внедряет в страницу («Поделиться» и отключение
  полноэкранного запроса), проверена отдельным тестом.

**Не проверено:** установка и запуск на живом Android. Эмулятора здесь нет (образы Android
качаются с google.com, он закрыт), телефона — тем более. Поэтому первый запуск на твоём
телефоне и есть настоящая приёмка. Если что-то не так — пришли скриншот, поправлю.

## Что делать утром

1. Скинуть `zhestyanki-1.0.0.apk` на телефон, разрешить установку из неизвестных источников,
   поставить. Проверить: иконка и имя «Жестянки», игра сразу альбомная и на весь экран,
   звук, бой, сохранение прогресса, режим «в самолёте».
2. Сохранить ключ подписи в надёжное место.
3. Дальше — магазины: **RuStore → Huawei AppGallery → Google Play** (тексты карточек — в `STORE.md`).

## Запасной путь (если WebView где-то подведёт)

Можно собрать «обёртку над сайтом» (TWA) через <https://www.pwabuilder.com/> — для этого
в репозитории лежит `app.webmanifest`. Минус: нужен файл подтверждения
`https://alexbadnik-dev.github.io/.well-known/assetlinks.json` (отдельный репозиторий
`alexbadnik-dev.github.io`, которого пока нет), и без интернета первый запуск не работает.
Пока этот путь не нужен.
